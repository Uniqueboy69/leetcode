# LeetCode Solutions

A collection of solutions to LeetCode problems, demonstrating problem-solving approaches and algorithmic thinking.

## 📋 Overview

This repository contains solutions to various LeetCode coding problems. Each solution includes:
- **Problem description** and approach explanation
- **Clean, well-commented code**
- **Time and Space Complexity analysis**
- **Multiple approaches** (when applicable)

## 🎯 Problem Categories

- **Array & String** - Manipulation and searching techniques
- **Linked List** - Node-based data structure problems
- **Tree & Graph** - Traversal and pathfinding algorithms
- **Dynamic Programming** - Optimization through memoization
- **Hash Table** - Efficient lookups and grouping
- **Stack & Queue** - LIFO/FIFO data structure problems
- **Sorting & Searching** - Binary search, quicksort, mergesort
- **Math & Bit Manipulation** - Mathematical and bitwise operations
- **Greedy Algorithms** - Optimization through greedy choices
- **Backtracking** - Recursive problem-solving patterns
